# V1.0.5 Tag Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build version 1.0.5 with editable default template management, shared tag semantic guidance, preview-side tag adding, stronger CLI health checks, timeout tuning, and preview reliability fixes.

**Architecture:** Keep the plugin's existing single-file browser app shape, but extract tag template and semantic-rule concerns into shared helpers inside `plugin.js` / `cli-backends.js` before any larger split. Preserve the user's updated default pool and semantic rules as the source baseline. Do not auto-create, merge, or delete Eagle global tags.

**Tech Stack:** Eagle plugin HTML/CSS/JavaScript, localStorage, Node child_process, Node test runner, PowerShell packaging.
