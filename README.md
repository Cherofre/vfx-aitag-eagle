# 特效 AI 标签管理 Eagle 插件

这是一个独立 Eagle 插件，用于给游戏特效类图片、动图、视频和可预览设计文件生成受控标签。

## 功能

- 打开插件时读取 Eagle 标签管理里的标签，可选择读取全部标签，或只读取某个 Eagle 标签组内的标签。
- AI 只能从标签池中选择标签，返回池外标签会被过滤。
- 可导入默认特效标签模板，默认模板可在本机查看、搜索、增删、重命名和重置；点击“刷新 Eagle 标签”会按当前标签来源重新读取 Eagle 标签。
- 支持通过“追加当前选中”或采集条里的“收集选中”连续采集 Eagle 当前选中的单个或多个素材，重复追加会自动去重。
- 支持图片、GIF、APNG、动态 WebP、视频和可预览设计文件。
- 视频/动图通过 FFmpeg 抽帧后分析，抽帧频率范围为最高 8 帧/秒、最低 3 秒/帧。
- 默认分析 Eagle 当前选中的素材，分析后可预览结果再写入标签；预览窗口内也可以直接新增、勾选或删除待写入标签，不会打断视频播放。
- 即使没有导入默认模板，分析时也会把本机默认模板作为兜底候选；AI 命中的模板兜底标签会在待确认标签上显示绿色 `+`，写入前可取消勾选。
- 批量分析过程中可暂停；单个分析结果可单独重新分析。
- 默认不把素材标题传给 AI，减少标题误导；可在“写入与诊断”里手动开启标题辅助。
- 支持 AI 重试、请求分块、结果缓存和批量写入进度显示，适合较多标签、较多抽帧或长批次任务。
- 支持环境健康检查、分析预设、分析进度显示、失败项一键重试、结果过滤，以及分析结果里的手动增删标签。
- 素材区只显示摘要和少量预览，素材过多时可打开“完整列表”局部滚动查看。
- 支持待分析素材清空、插件内右键菜单，以及会自动置顶的“置顶采集”模式；采集条可拖动并记住上次位置，窗口会按屏幕可用区域保护定位，条上可继续收集或清空队列。
- 高置信标签默认也进入待确认区，只有开启“自动写入高置信标签”后才会自动写入 Eagle。
- 支持在“全局 AI 提示词”中输入自定义分析偏好，并自动保存到本机插件设置。
- 支持本地 Claude CLI、Codex CLI 和 Eagle AI 三种后端；默认优先尝试 Claude CLI，再尝试 Codex CLI。

## 安装

1. 在 Eagle 中打开插件管理。
2. 选择本地安装插件。
3. 选择已打包插件：

   ```text
   dist\特效AI标签管理-cli.eagleplugin
   ```

开发调试时也可以选择本仓库文件夹安装，但日常试用建议安装 `dist\特效AI标签管理-cli.eagleplugin`。

## 迁移说明

当前 CLI 分支插件 ID 是 `VFX_AI_TAGGER_CLI`，会和作者原版插件并存为独立插件。因为 Eagle 会按插件 ID 隔离本地存储，旧插件设置不会自动迁移；首次打开后需要重新填写 Claude/Codex/Eagle AI 后端、诊断目录和分析参数。

## 使用前准备

- 如使用 Claude CLI：先在终端确认 `claude --help` 可运行，并完成 Claude Code 登录。
- 如使用 Codex CLI：先在终端确认 `codex --help` 可运行，并完成 Codex 登录。
- CLI 命令框可以先保留 `claude` / `codex`，插件会优先解析到原生 `.exe`；如果手动填写路径，请填写原生 `.exe`，不要填写 `.cmd` / `.bat` 脚本。
- 如使用 Eagle AI：Eagle 需要安装并配置官方 AI 模型套件，且 AI 模型套件里需要设置默认视觉模型。
- 视频、动图和设计文件预览分析依赖 Eagle 的 `ffmpeg` 扩展模块。

默认不再强制依赖 Eagle AI 模型套件。没有 API Key 时，可以只勾选 Claude CLI / Codex CLI；插件会调用本地 CLI 的已登录状态。

## 使用方式

1. 在 Eagle 中选中要分析的素材。
2. 从 Eagle 插件入口打开本插件，然后在“待分析素材”区域点击“追加当前选中”或“替换为当前选中”。
3. 如果还想继续收集素材，回到 Eagle 选择下一批素材，再点击“追加当前选中”；如需重新开始，用“替换为当前选中”或“清空”。
4. 素材很多时点击“完整列表”查看；需要减少窗口占用时点击“置顶采集”，插件会缩成较小的置顶采集窗，保留“收集选中 / 开始分析 / 清空队列 / 工作台”入口。采集条可以拖到合适位置，下次进入采集模式会优先恢复到上次位置。
5. 标签池默认会读取 Eagle 标签管理里的全部标签；如需限制范围，可在“Eagle 标签来源”中选择某个标签组；如果标签池为空，点击“导入默认模板”。需要调整默认模板时，点击“管理模板”，这些修改只保存在本机插件设置里，不会修改 Eagle 全局标签。
6. 在“AI 后端”中选择 Claude CLI、Codex CLI 或 Eagle AI，并点击“环境检查”确认本机依赖可用；本地 CLI 检查会执行 `--version`，失败时尝试 `--help`，不会发起 AI 分析请求。
7. 在“分析参数”中选择一个预设，或手动调整最大标签数、并发数、AI 重试次数、AI 请求分块、抽帧频率、最大帧数；如需统一分析偏好，可填写“全局 AI 提示词”。
8. 点击“开始分析”。
9. 确认分析结果后点击“写入标签”；如需重跑某个素材，点击该结果里的“重新分析”，或用“失败”过滤后点击“重试失败项”。

## 注意

- “删除标签池标签”只会在当前插件窗口中从候选池移除，不会删除 Eagle 的全局标签，也不会移除素材已有标签；点击“刷新 Eagle 标签”会按当前“Eagle 标签来源”重新读取，不包含默认模板标签。
- “管理模板”只维护本地默认模板；导入模板会把模板标签加入当前候选池，但不会自动创建 Eagle 标签。
- 默认模板兜底标签只是在分析阶段作为可选候选，命中后仍需在结果里确认；除非点击“写入标签”，否则不会写入素材或创建 Eagle 全局标签。
- 插件内右键菜单只作用于插件窗口内的素材、结果和标签，不会注入或改写 Eagle 主界面的宿主右键菜单。
- AI 返回的标签如果不在标签池里，会显示在“已过滤”中，但不会写入素材。
- “AI 请求分块”会把图片帧和标签池拆成多次请求，能缓解上下文不足，但会降低速度；默认 256K 基本等同尽量单次发送。
- 高抽帧频率会增加分析时间和模型成本，长视频建议配合最大帧数限制使用。
- Claude CLI 会通过本地文件路径读取图片/抽帧，Codex CLI 会通过 `codex exec --image` 附加图片；如果 CLI 没有登录、命令路径不对、命令解析到 `.cmd` / `.bat` 脚本或超过分析超时，插件会自动尝试下一个已启用后端。CLI 分析默认超时为 180 秒，可在设置中调整。
