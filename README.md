# 特效 AI 标签管理 Eagle 插件

这是一个独立 Eagle 插件，用于给游戏特效类图片、动图、视频和可预览设计文件生成受控标签。

## 功能

- 打开插件时读取 Eagle 标签管理里的标签，可选择读取全部标签，或只读取某个 Eagle 标签组内的标签。
- AI 只能从标签池中选择标签，返回池外标签会被过滤。
- 可导入默认特效标签模板，并支持手动新增/移除候选标签；点击“刷新 Eagle 标签”会按当前标签来源重新读取 Eagle 标签。
- 支持通过“导入素材”按钮手动选择文件分析，避免 Eagle 当前选中项无法识别时卡住。
- 支持图片、GIF、APNG、动态 WebP、视频和可预览设计文件。
- 视频/动图通过 FFmpeg 抽帧后分析，抽帧频率范围为最高 8 帧/秒、最低 3 秒/帧。
- 默认分析 Eagle 当前选中的素材，分析后可预览结果再写入标签。
- 批量分析过程中可暂停；单个分析结果可单独重新分析。
- 高置信标签默认也进入待确认区，只有开启“自动写入高置信标签”后才会自动写入 Eagle。
- 支持在“全局 AI 提示词”中输入自定义分析偏好，并自动保存到本机插件设置。

## 安装

1. 在 Eagle 中打开插件管理。
2. 选择本地安装插件。
3. 选择本文件夹：

   ```text
   C:\Users\xiangzx\Documents\特效设计稿\vfx-ai-tagger
   ```

## 使用前准备

- Eagle 需要安装并配置官方 AI 模型套件。
- AI 模型套件里需要设置默认视觉模型。
- 插件依赖 Eagle 的 `ai-sdk` 和 `ffmpeg` 扩展模块。

## 使用方式

1. 在 Eagle 中选中要分析的素材。
2. 打开插件，点击“刷新选择”。
3. 如果选中项没有识别到，点击“导入素材”手动选择要分析的文件。
4. 标签池默认会读取 Eagle 标签管理里的全部标签；如需限制范围，可在“Eagle 标签来源”中选择某个标签组；如果标签池为空，点击“导入默认模板”。
5. 调整最大标签数、并发数、抽帧频率、最大帧数；如需统一分析偏好，可填写“全局 AI 提示词”。
6. 点击“开始分析”。
7. 确认分析结果后点击“写入标签”；如需重跑某个素材，点击该结果里的“重新分析”。

## 注意

- “删除标签池标签”只会在当前插件窗口中从候选池移除，不会删除 Eagle 的全局标签，也不会移除素材已有标签；点击“刷新 Eagle 标签”会按当前“Eagle 标签来源”重新读取，不包含默认模板标签。
- 通过“导入素材”选择的外部文件可以分析，但如果不是 Eagle 资源库项目，不能直接写回 Eagle 标签。
- AI 返回的标签如果不在标签池里，会显示在“已过滤”中，但不会写入素材。
- 高抽帧频率会增加分析时间和模型成本，长视频建议配合最大帧数限制使用。
